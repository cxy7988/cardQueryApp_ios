# QueryApp - 校园费用查询应用

一个专为校园生活设计的费用查询iOS应用，支持饭卡余额、水费、电费的实时查询。

## 📱 功能特性

### 🔐 安全登录
- **邮箱验证登录**：使用 @wku.edu.cn 邮箱接收验证码
- **安全保障**：验证码5分钟有效期，自动过期保护
- **登录状态管理**：持久化登录状态，重启应用无需重新登录

### 🔍 多项查询
- **饭卡余额查询**：实时获取校园卡余额信息
- **水费查询**：查看宿舍水费余额和使用情况
- **电费查询**：监控宿舍电费余额和用电量

### 🏠 智能房间配置
- 楼栋、楼层、房间级联选择
- 基于JSON数据的房间信息管理
- 配置完整性验证

### 📊 历史记录
- 本地持久化存储查询历史
- 支持查看、删除和清空历史记录
- 查询状态可视化显示

### ⚙️ 个性化配置
- **基础配置**：房间信息选择
- **开发者模式**：API参数自定义配置
- **配置管理**：保存、重置、导入导出

## 📋 使用说明

### 首次使用
1. **登录验证**：输入您的 @wku.edu.cn 邮箱地址
2. **接收验证码**：检查邮箱并输入6位验证码
3. **完成登录**：验证成功后自动进入主界面

### 房间配置
1. 点击设置按钮进入配置页面
2. 选择您的楼栋、楼层和房间
3. 如需自定义API参数，进入"开发者模式"
4. 保存设置并返回主界面

### 查询操作
1. 确保房间信息已正确配置
2. 点击"查询"按钮获取实时数据
3. 查看历史记录了解用费趋势

### 配置管理
- **登录认证**：必须使用 @wku.edu.cn 邮箱完成验证
- **房间配置**：必须完成才能查询水电费
- **卡用户ID**：可选配置，未设置时跳过卡余额查询
- **开发者参数**：高级用户可自定义API接口参数
- **退出登录**：在设置页面可安全退出登录

## 🔒 隐私与安全

- 所有数据本地存储，不上传至第三方服务器
- 敏感配置信息仅在设备本地保存
- 网络请求仅访问官方查询接口

## 🛠 开发者说明

### API接口
- **卡余额**：`https://webapp.xiaofubao.com/card/getCardMoney`
- **水电费**：`https://application.xiaofubao.com/app/electric/queryRoomSurplus`

### 配置参数
- `cardUserId`：饭卡查询用户ID
- `roomUserId`：水电费查询用户ID  
- `deviceId`：设备标识符
- `areaId_elec`：电费查询区域ID
- `areaId_water`：水费查询区域ID

### 抓包获取参数
1. 使用浏览器开发者工具或代理工具
2. 在官方查询页面进行一次查询
3. 从请求头的Cookie中获取`shiroJID`值
4. 从请求参数中获取相应的ID值
